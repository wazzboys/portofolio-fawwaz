Mengenal Teknologi Jaringan

Penjelasan komunikatif dan mendalam mengenai pilar teknologi infrastruktur IT yang saya pelajari:

Apa itu MikroTik?

Perangkat Gateway & RouterOS Management

MikroTik adalah nama perusahaan sekaligus merek sistem operasi (RouterOS) dan perangkat keras (RouterBoard) yang dirancang khusus untuk mengelola lalu lintas jaringan internet.

// FUNGSI UTAMA YANG SAYA PELAJARI:

• Mengambil koneksi internet dari ISP lalu menyebarkannya secara aman ke pengguna lokal (LAN/WiFi).

• Manajemen pembagian kecepatan internet (Bandwidth Limiting via Simple Queue).

• Pembuatan akses internet berbayar/voucher menggunakan sistem Captive Portal Hotspot.

Apa itu Cisco?

Standar Industri Enterprise Network Global

Cisco adalah standar industri teknologi jaringan global terbesar untuk skala gedung/perusahaan besar (Enterprise). Berfokus pada keandalan tinggi switch, router kelas atas, dan protokol kompleks.

// FUNGSI UTAMA YANG SAYA PELAJARI:

• Membagi jalur jaringan menjadi beberapa grup terpisah yang aman menggunakan VLAN.

• Menghubungkan antar-VLAN melalui proses Inter-VLAN Routing (Trunking).

• Mengatur rute pengiriman data otomatis dan efisien dengan routing dinamis OSPF.

Apa itu Debian Server?

Sistem Operasi Server Open-Source Stabil

Debian Linux adalah sistem operasi open-source yang sangat terkenal karena ketahanan, keamanan, dan kestabilannya saat digunakan sebagai pusat komputer server penyedia layanan internet.

// LAYANAN SERVER YANG SAYA KONFIGURASI:

• SSH Remote: Mengendalikan server dari jarak jauh tanpa layar monitor fisik.

• FTP Server: Menyediakan tempat penyimpanan & pengiriman file terpusat.

• Web Server: Menampilkan halaman situs web agar dapat diakses pengguna di jaringan.

Media Fisik & CCTV?

Pengabelan LAN, Coaxial & Sistem Kamera Security

Jaringan tidak akan berjalan tanpa fondasi kabel fisik dan keamanan tempat yang baik. Kabel fisik mentransmisikan sinyal listrik/data, sementara CCTV menjaga keamanan lingkungan kerja secara terintegrasi.

// PENGERJAAN FISIK YANG SAYA KUASAI:

• Kabel UTP (LAN): Pengerimpingan RJ-45 standar Straight dan Crossover.

• Kabel Coaxial: Perakitan konektor BNC untuk hantaran video analog.

• Sistem CCTV: Pemasangan IP Camera, DVR/NVR, dan konfigurasi rekaman.
